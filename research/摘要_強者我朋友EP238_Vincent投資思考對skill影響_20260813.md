# 《強者我朋友》EP238：Vincent 投資思考方式對 Hermes skill 的影響

- 研究日期：2026-08-13
- 影片：https://www.youtube.com/watch?v=1ydp1h8FNG0
- 影片標題：39歲從 J.P. Morgan 退休！專業分析師怎麼看財富自由？
- 來賓：Vincent，曾任 J.P. Morgan 分析師，後投入投資、教學與《曼報 Pro》內容工作
- 研究目的：不只整理影片，而是把其中可以重複使用的決策方法轉成對現有 Hermes skill 的架構影響。
- 結論信心：高，影片主張清楚；對 skill 的建議屬方法論設計判斷，不是外部事實宣稱。

## 一、先講結論

這集最珍貴的地方，不是教我們多加幾個財務指標，而是把投資從「找一個神奇分析法」改成一套完整的決策系統：

> **先理解自己，再理解公司；先找驅動因子，再驗證市場反映；用多種工具拼出機率與賠率，最後把確信程度轉成部位，而不是把單一預測當真理。**

對我們現有 skill 的最大影響有五個：

1. **ROIC 應從普通財務指標升格為商業模式入口。** 不是只問公司賺多少，而是問投入多少資本，能產生多少可持續回報。
2. **所有研究要明確寫出 Driver。** 不能只堆營收、毛利率、題材，必須說清楚「什麼事件透過什麼機制改變獲利與估值」。
3. **Conviction 要與機率分開。** 看對機率只有四、五成不代表不能投資，關鍵是何時加大、何時退出，以及報酬／風險是否不對稱。
4. **取消聖杯式投資觀。** 基本面、技術面、籌碼、宏觀資料不是互相競爭的宗派，而是不同問題的感測器。
5. **Skill 要對齊使用者，而不是假設全能分析師。** 研究深度、持有週期、波動承受力、耐心與想像力不同，應影響最後的策略建議。

這不是叫我們把 skill 寫得更厚。相反地，應該把這五個原則寫進薄入口，讓每次產出的研究報告變厚、變有證據、變可復盤。

## 二、影片真正教的是「如何下注」，不是「買什麼」

### 1. 最差的投資建議，是直接叫人買進賣出

Vincent 認為，單次買賣建議的問題在於不可複製。賺錢時使用者只記得結果，踩到一次雷後，傷害卻可能遠大於先前的小利潤。真正有價值的是建立能持續重複使用的邏輯與方法。[1]

這直接對應我們目前的輸出習慣：`YES / NO / HOLD` 很適合做決策門，但不能變成沒有推理鏈的紅綠燈。決策必須附帶：

- 這次下注的 Driver 是什麼。
- 哪些證據支持 Driver。
- 市場已反映多少。
- 哪個觀察結果會推翻原始假設。
- 部位大小為什麼與確信程度相稱。

### 2. 投資不是找唯一聖杯

影片批評投資人追求單一聖杯，例如只信基本面、只信技術面或只信籌碼面。各種方法其實是不同情境下的資訊來源，過度排斥其他工具會製造偏見。[1]

這個觀點也符合 Taleb 對運氣、能力、不確定性與決策的提醒：成功結果不必然等於能力，市場中的幸運者很容易被事後故事包裝成天才。[2]

因此，我們不應把「基本面優先」寫成「基本面排他」。正確分工是：

| 工具 | 它回答的問題 | 不能回答的問題 |
|---|---|---|
| 商業模式／ROIC | 公司如何把資本變成回報 | 股價何時反映 |
| 財報與產業資料 | 獲利是否正在變化 | 短線資金何時轉向 |
| 技術面 | 趨勢、位置、風險報酬與進場效率 | 公司長期價值 |
| 籌碼與資金流 | 誰在買、誰在減碼、擁擠度 | 公司是否真的有護城河 |
| 宏觀與政策 | 外部環境、需求與折現率 | 個別公司能否執行 |

## 三、最應該補進 equity-research-analyst 的東西：ROIC不是表格欄位，而是商業模式壓力測試

### 1. 為什麼Vincent從ROIC開始看公司

影片把「好公司」重新定義成：不是營收最大、利潤最高或成長最快，而是用較少資本取得較高、且能持續的回報。[1]

ROIC的標準概念，是用稅後營業利益除以投入資本，再與資金成本比較；真正重要的是 ROIC 是否高於 WACC，以及這個差額能否維持，而不是孤立看一個百分比。[4]

這對現有個股研究的影響很大。現在研究容易先寫：

- 營收成長。
- 毛利率提高。
- EPS上修。
- AI需求強。

之後才補商業模式。Vincent的順序應該反過來：

> **先問公司每投入一塊錢，能不能產生更高的經濟回報，再問成長是否值得追。**

### 2. ROIC必須和「再投資跑道」一起看

高ROIC本身不夠。若公司只能把很少的錢以高報酬投出去，成長天花板可能很低；若公司有長期高ROIC，且能把大量新增資本繼續投入高報酬用途，才是真正有價值的複利機器。[1]

未來研究應增加四個問題：

1. 公司目前ROIC是多少，趨勢向上還是向下。
2. 新增資本投到哪裡，與既有業務是否同樣高回報。
3. 成長需要多少營運資金、設備、庫存與應收帳款。
4. 擴張後的邊際ROIC是否低於歷史ROIC。

這會直接改善我們對「營收爆發但資本支出、庫存和應收帳款同步爆發」公司的判斷。

### 3. 對現有 skill 的具體改法

`equity-research-analyst` 不需要新增一個冗長的「ROIC章節」。應在商業模式問題中加入一條薄契約：

> **把公司看成資本配置機器：說明投入資本、獲利回報、再投資跑道與邊際ROIC，並與同業商業模式比較。**

詳細公式、產業例外與計算口徑放到 references；報告本身才放計算結果、趨勢與判讀。

## 四、所有研究都要從「驅動因子」開始，不要從資料堆開始

### 1. 初級、 中級、高級的能力分層

Vincent對投資者能力的分層很實用：[1]

- **初級**：能解釋一件事發生後，股票為什麼可能改變。
- **中級**：能思考未來、知道市場現在已反映什麼。
- **高級**：能站到產業領導者的角度，推演下一代產品、資本配置與競爭陣營。

這不是炫技分級，而是輸出驗收標準。現有研究常做到「描述發生了什麼」，但不一定做到「為什麼會改變EPS」與「市場是否已反映」。

### 2. 建議新增 Driver Chain

每個研究主張都應用一條最短因果鏈：

```text
事件／變化
→ 產品、供需、價格或成本機制
→ 營收／毛利率／營益率／現金流
→ EPS或長期ROIC
→ 市場估值與股價反應
→ 否決條件
```

例如「AI需求強」不合格；合格版本是：

```text
AI伺服器平台升級
→ 每台設備的某零組件內容值增加
→ 高毛利產品占比上升
→ 毛利率與營益率改善
→ EPS預估上修
→ 若股價漲幅超過EPS上修幅度，估值擴張風險升高
```

這條鏈比再加十個新聞連結有用。

## 五、Conviction不是喊信心，而是部位與等待的規則

### 1. 機率不高，仍可能值得下注

影片提到，即使專業投資人事前判斷正確的比例只有約四、五成，仍可能透過確信程度、加碼、減碼與停損管理取得優勢。[1]

這裡要避免一個常見誤讀：不是「看錯沒關係」，而是：

> **單次預測的命中率，不等於整套投資系統的期望值。**

投資決策至少要分開四個維度：

| 維度 | 問題 |
|---|---|
| Probability | 事情發生的機率是多少 |
| Payoff | 發生時賺多少，失敗時賠多少 |
| Conviction | 我為什麼比一般市場更有信心 |
| Position | 這個信心應該轉成多大部位 |

### 2. 對現有台股 skill 的影響

目前 `taiwan-stock-analyst` 已有 `YES / NO / HOLD`、劇本六座標與部位上限，這是好的骨架；但它仍可補一個「確信與賠率」欄位，避免決策只剩方向與價格：

```text
判定：YES / NO / HOLD
主要Driver：
市場已反映：
我方優勢資訊：
成功機率：高／中／低
成功報酬／失敗損失：
Conviction：高／中／低
部位如何反映Conviction：
```

`Conviction` 不應由語氣決定，而要由證據品質、資訊差、催化劑距離、估值安全邊際與否決條件是否清楚共同決定。

### 3. 高確信不是高部位的自動通行證

如果證據很強但估值極高，可能是「高基本面信心、低投資報酬信心」。如果估值便宜但商業模式不懂，可能是「高安全邊際想像、低商業理解」。兩者不能混成一個emoji。

## 六、最值得補進研究流程的概念：先認識自己，再選投資風格

### 1. 能力圈不是口號，而是研究範圍邊界

影片建議投資人接受自己的個性與能力：沒有耐心，就不應硬做長期價值投資；缺少想像力，就不要硬押高度依賴遠期想像的公司。[1]

這與 Berkshire 對能力圈的說法一致：不需要成為所有公司的專家，但必須知道自己能力圈的邊界。[3]

### 2. 這對我們的 skill 有兩層影響

#### 第一層：Skill不能假設模型是全能投資經理

目前skill容易把所有任務都推向同一種深度研究格式。更好的做法是先判斷任務型態：

- **核心長線型**：ROIC、再投資跑道、護城河、侵蝕風險。
- **景氣循環型**：供需、價格、庫存、產能、邊際獲利。
- **事件交易型**：催化劑、預期差、時間窗、風險上限。
- **高波動題材型**：敘事驗證、估值安全邊際、流動性與退出條件。

#### 第二層：輸出要允許「不適合做」

如果研究顯示公司必須靠十年後的市場想像才能成立，且製作人要的是1D至1W交易，就應該直接說週期錯配，而不是硬產一篇長期看多報告。

## 七、不能把基本面、技術面與籌碼面揉成一鍋

影片不是主張所有資料權重相同，而是主張不同工具回答不同問題。[1]

因此，skill架構應保留關注點分離：

- `equity-research-analyst`：公司、產業、ROIC、估值與長期侵蝕。
- `taiwan-stock-analyst`：交易週期、價格、籌碼、部位與出場。
- `grounded-citations`：證據鏈與來源誠信。
- `trade-review`：事後檢查原始假設、執行品質與結果偏誤。
- `meme-trace`：敘事起源、傳播與硬指標驗證。

真正應該新增的是「共同詞彙」，不是一個巨大總 skill：

- Driver
- Market-implied
- Conviction
- Payoff
- Invalidation
- ROIC
- Circle of competence
- Process versus outcome

這符合我們目前的模組化方向，也比把所有分析法塞進 `taiwan-stock-analyst` 更乾淨。

## 八、這集對現有 skill 的優先級影響

### P0：應優先處理

#### 1. `equity-research-analyst`

補入：

- ROIC／投入產出比作為商業模式入口。
- Driver Chain。
- 市場已反映什麼。
- 邊際ROIC與再投資跑道。
- 能力圈與持有週期適配。

#### 2. `taiwan-stock-analyst`

補入：

- Probability、Payoff、Conviction、Position四分法。
- 高確信不等於高部位。
- 交易週期與研究週期錯配檢查。

### P1：應在下一輪處理

#### 3. `trade-review`

從「賺錢或賠錢」改成：

- 原始Driver是否成立。
- 結果是否可能只是幸運。
- 是否有替代情境被忽略。
- 部位是否與當時確信程度一致。
- 失敗是分析錯、執行錯，還是風險控制錯。

#### 4. `investment-playbook-review`

增加「賠率檢查」：如果成功只賺一小段、失敗會造成大損失，即使勝率看似高，也不能通過。

#### 5. `research/grounded-citations`

目前已經強調來源與未確認標記，下一步可加一個輕量規則：

> **每個主要結論至少有一條因果機制與一個否決條件，來源不是機制本身。**

### 暫時不應動的地方

- 不新增一個叫 `vincent-investing` 的模仿型 skill。
- 不把影片的個人風格、金句或語氣硬寫進股癌 skill。
- 不把 ROIC 變成所有股票同一套機械排名，因為金融、保險、資產輕平台與景氣循環業的投入資本口徑不同。
- 不把「高確信」變成模型主觀自評分數，否則只是另一個聖杯。

## 九、最小可行改造方案

如果要落地，我建議只做三個薄改動，不先重寫整個 skill 生態：

### 改動一：研究輸出加一段「投資命題」

```markdown
> 投資命題：{事件}透過{機制}使{獲利／ROIC／估值}改變；市場尚未／已經反映{程度}。
> 否決條件：若{可觀測指標}發生，命題失效。
```

### 改動二：交易輸出加一段「賠率與確信」

```markdown
- 成功機率：
- 成功報酬：
- 失敗損失：
- Conviction來源：
- 部位是否與Conviction匹配：
```

### 改動三：研究驗收加入「能力圈與週期適配」

```markdown
- 這是長期價值、景氣循環、事件交易，還是高波動題材？
- 使用者的持有週期與這個命題匹配嗎？
- 哪個部分是我們真正理解，哪個部分只是借用市場敘事？
```

這三項就能吸收影片最重要的思考，不需要增加大量硬規則。

## 十、最終判定

這部影片對我們不是「再加一個投資流派」，而是一次架構校正：

> **現有 skill 已經有資料、引用、交易劇本與研究結構，但還需要把「公司如何創造回報」「事件如何改變獲利」「市場已反映什麼」「我有多大優勢」「部位如何匹配賠率」串成同一條決策鏈。**

如果只做一件事，我會先改 `equity-research-analyst`：把 ROIC、Driver Chain、Market-implied 與邊界條件放進入口。因為這會反過來改善個股研究、目標價、AI題材判讀與交易決策，而不是只改善文字風格。

但現在我**不直接修改 skill**。理由很簡單：製作人問的是「研究並思考影響」，不是「立即改檔」。這份報告先留下設計決策與最小改造方案，等你確認方向後，再按 P0順序改動並跑 lint、路由與真實案例驗收。
