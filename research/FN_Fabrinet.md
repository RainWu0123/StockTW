# Fabrinet（NYSE: FN）：AI光通訊的隱形製造平台，但不是高毛利光學品牌

**報告日期**：2026-08-19（台灣）  
**資料截止**：2026-08-19  
**估值期間**：12個月，主要評價FY2027正常化EPS  
**信心等級**：中  
**研究判斷**：HOLD／偏多，等待現金流與庫存驗證  

> 結論：Fabrinet是AI光通訊供應鏈裡非常稀缺的高複雜度製造平台，FY2026營收年增36%、Q4資料中心收入年增68%，基本面沒有壞；但它本質仍是毛利率約12%的代工廠，不是擁有產品定價權的Lumentum或Coherent。2026年8月18日財報後收482.59美元，我給保守基準合理價586美元；若用12個月後市場開始交易FY2028的方式，基準可到662美元，因此合理區間調整為480～660美元。股價大跌後估值改善，但FY2026自由現金流只剩420萬美元、存貨年增76%，不能把財報beat直接當成無腦買點。[1][2][5]

## 它不是普通EMS，卻也不是光學IP公司

Fabrinet替光通訊、資料中心、工業雷射、汽車與醫療OEM提供製程設計、供應鏈管理、光學精密封裝、組裝、整合與測試。公司承接高複雜度、任何批量的產品，核心工廠位於泰國，並以美國Fabrinet West作為新產品導入（NPI）前哨，再把成熟產品轉到泰國低成本量產。[1][2][3]

價值鏈位置可以概括為：

```text
客戶掌握晶片、光學設計與產品IP
→ Fabrinet參與NPI、製程工程與量產設計
→ 在泰國執行高精度封裝、組裝、整合、測試
→ 客戶省下自建複雜光學產線、人才與良率爬坡成本
```

Fabrinet的護城河不是專利壟斷，而是：

1. 光纖對準、微組裝、精密光學與矽光子封裝的製程know-how。
2. 客戶產品通常需要3～6個月以上驗證，轉廠會重新承擔認證與良率風險。
3. Fabrinet West靠近矽谷客戶，NPI成功後可直接轉入泰國大量生產。
4. Factory-within-a-factory與資訊隔離，能同時服務互相競爭的OEM。
5. 泰國大規模、低成本、非中國製造基地，在美國限制中國光模組的情境下具戰略價值。[2][4]

但別把它神化。Fabrinet沒有權利拿客戶IP另行銷售，製程改善也常須讓渡給客戶；客戶仍可內製或轉單。這是一個深度嵌入、切換成本高的製造服務護城河，不是產品定價權護城河。[2]

## 財報漂亮，但利潤率提醒你它仍是代工

| 項目 | FY2026 Q4 | 年增／比較 |
|---|---:|---:|
| 營收 | 13.16億美元 | +45% |
| GAAP毛利率 | 12.0% | 去年12.2% |
| non-GAAP毛利率 | 12.2% | 去年12.5% |
| GAAP營益率 | 10.2% | 去年9.8% |
| non-GAAP營益率 | 10.9% | 三年高點 |
| GAAP EPS | 3.83美元 | 去年2.42美元 |
| non-GAAP EPS | 4.10美元 | 去年2.65美元 |

FY2026全年營收46.41億美元、年增35.7%；GAAP營業利益4.63億美元、年增42.7%；GAAP EPS 13.05美元、non-GAAP EPS 14.09美元。[1][3]

真正的訊號是營業利益成長快過營收，而毛利率沒有擴張。原因是SG&A只占營收約1.3%，營收放大後形成營運槓桿。換句話說，Fabrinet的獲利改善主要靠規模，而不是突然取得更高產品毛利。

## 資料中心已成第一大業務，DCI、HPC與新transceiver是三條主線

Q4新分類如下：[3][4]

| 類別 | Q4營收 | 占比 | 年增 | 季增 |
|---|---:|---:|---:|---:|
| Data Center | 6.69億美元 | 51% | +68% | +13% |
| Communications Infrastructure | 4.13億美元 | 31% | +40% | +1% |
| Automotive、Industrial及其他 | 2.34億美元 | 18% | +8% | +9% |

Data Center包含：

- DCI：Q4年化營收run-rate已超過10億美元，是最大增量。
- HPC：主要大型hyperscaler的下一代silicon平台持續爬坡。
- Transceiver：既有主要客戶以外，新增hyperscaler-direct與merchant program；一個直接客戶專案已於Q1 FY2027開始，merchant專案預計12月季與2027年初陸續放量。
- 800G／1.6T：需求強，但公司拒絕替NVIDIA公布具體產品時程，不能把所有新營收都直接等同NVIDIA 1.6T。

Communications Infrastructure則來自telecom systems、衛星通訊、長距離光網路元件等，代表Fabrinet不是只靠資料中心模組。

## NPO比CPO更近，OCS是另一張尚未大幅入帳的牌

公司已替數個客戶製作CPO裝置，但尚未進入完整大量生產。管理層認為NPO介於可插拔模組與CPO之間，更接近Fabrinet既有量產能力，且在6.4T、12.8T後封裝複雜度與良率更重要，因此NPO可能比CPO更早形成實質營收。[4]

OCS製造技術也與既有產品相近，公司已小量出貨並認為會參與後續大規模放量。但目前CPO、NPO、OCS都沒有獨立收入揭露，因此只能當選擇權，不能拿未公開TAM直接灌進估值。

## 客戶變多了，但集中度反而更高

FY2026四大客戶：[2][4]

| 客戶 | FY2026營收占比 |
|---|---:|
| Cisco | 約20% |
| NVIDIA | 約16% |
| Nokia | 約11% |
| Amazon | 約11% |
| **合計** | **約57.4%** |

NVIDIA占比由FY2025的27.6%降至16%，表面上降低單一客戶風險；但四大客戶合計占比由45.8%升至57.4%，公司只是從單押NVIDIA轉成同時押Cisco、NVIDIA、Nokia、Amazon。

這有兩面：

- 正面：成長不再只靠一個NVIDIA產品週期。
- 負面：四家任何一家砍單、內製、併購後整合供應鏈，都會明顯影響Fabrinet。

客戶提供的需求能見度已看到2027年底與更後面，但管理層明確說這些不是firm orders，不能把forecast當成不可取消長約。[4]

## 產能擴張足以支撐三倍營收，也足以製造下一輪災難

公司FY2026退出時年化營收run-rate約53億美元。現有與規劃產能包括：[3][4]

- Pinehurst辦公空間轉產線後：支撐約55～58億美元。
- Chonburi Building 10：增加約30～35億美元營收容量，預計2027年初完成。
- Navanakorn：增加約2～2.5億美元。
- Santa Clara新園區：增加約2～2.5億美元NPI能力。
- Chonburi未來另兩座工廠：各增加約18～21億美元。
- 長期總容量：估計可支撐125～140億美元營收。

這不是營收指引，而是物理產能上限。若客戶需求落空，龐大廠房、設備、存貨與人力會反過來拖累ROIC。

## 最大黃燈不是Q1 EPS，而是自由現金流與存貨

FY2026：[1][2]

- 營業現金流2.57億美元，低於前一年的3.28億美元。
- CapEx由1.21億升至2.53億美元。
- 自由現金流由2.07億美元降至僅420萬美元，幾乎歸零。
- 存貨由5.81億增至10.21億美元，年增75.8%。
- 應收帳款由7.59億增至10.18億美元，年增34.1%。
- PP&E由3.81億增至6.15億美元，年增61.6%。
- 現金與短期投資約8.75億美元，財報日無債務；財報後另借入約7500萬美元支應CapEx。

存貨成長遠快於營收，不一定代表賣不掉，可能是替新專案、長交期元件與供應短缺預先備料；但若客戶forecast改變，這會成為跌價與現金回收風險。

因此，8月18日股價大跌19.4%，不是因為Q4財報差。市場真正擔心的是：

1. FY2027成長很強，但non-GAAP毛利率仍只有約12%。
2. Datacom／NVIDIA產品過渡與元件供應限制仍存在。
3. FCF幾乎歸零，庫存快速上升。
4. 財報前股價已把數年後的產能與CPO故事先算進去。[1][4][5]

## 同業比較：不能拿Fabrinet的PE直接套Lumentum

- Fabrinet：代工與精密封裝，Q4 non-GAAP毛利率12.2%、營益率10.9%。
- Coherent：擁有材料、雷射、元件與模組IP，Q4 non-GAAP毛利率40.2%。[8]
- Lumentum：擁有雷射、OCS、模組等產品與IP，獲利率也顯著高於Fabrinet。
- Jabil、Celestica、Sanmina：同屬製造服務競爭者，但光學精密製程純度與客戶組合不同。

Fabrinet應享有AI光通訊、高成長、低成本泰國製造與高ROIC溢價；但不能因為服務Lumentum、NVIDIA或Cisco，就獲得相同的產品公司倍數。

## 自建估值

| 情境 | FY2027 non-GAAP EPS | 目標PE | 合理價 | 核心假設 |
|---|---:|---:|---:|---|
| 空頭 | 15.0美元 | 24倍 | 360美元 | 成長降至20%以下、毛利率<12%、存貨與FCF惡化 |
| **基準** | **18.3美元** | **32倍** | **586美元** | 營收約60～62億、營益率約11%、新transceiver與HPC爬坡 |
| 多頭 | 21.0美元 | 38倍 | 798美元 | FY2027營收增速接近或高於FY2026、NPO／OCS提早放量、FCF恢復 |

以2026年8月18日收盤482.59美元計，基準上行約21%，空頭下跌約25%，多頭上行約65%。[5]

我的586美元低於多數券商650～750美元，原因是我不把125～140億美元產能當成已簽訂營收，也對12%毛利率、零FCF與高庫存保留折價。

### 12個月後改看FY2028的交叉估值

另一種合理做法，是假設12個月後市場開始交易FY2028 EPS：基準先估FY2027營收62億美元、non-GAAP淨利率10.8%、EPS 18.4美元，再假設FY2028 EPS成長20%至22.1美元，給30倍PE，得到約662美元。這個方法與券商650～750美元區間較接近，但多加了一層「FY2028仍成長20%」的假設。

因此我不把662美元直接取代586美元，而是將兩者並列：

- **586美元**：以FY2027 EPS直接評價，較保守。
- **662美元**：以FY2028 EPS折現／前瞻評價，要求新產能、NPO／OCS與新transceiver繼續放量。
- **最終基準合理帶：586～662美元。**

## 投資判斷與劇本

**定位**：高成長AI光通訊製造平台，不是高毛利光學IP公司。策略類型屬高波動成長股。

- 480美元附近：估值已從財報前大幅降溫，可觀察或建立小部位，但不是安全價。
- 430～460美元：開始有較明顯風險報酬。
- 360～400美元：接近空頭估值，前提是基本面沒有同步惡化。
- 580～620美元：基準合理區，需靠FY2027 EPS上修支撐。
- 650美元以上：重新進入券商目標與高估值區，不追。

若需要部位建議，單一FN初始部位不超過淨值3%～5%，確認FCF與庫存後再提高，總上限10%。

## 上修條件

1. FY2027 Q1／Q2營收持續高於指引上緣。
2. Data Center季增維持雙位數，DCI、HPC與transceiver三者同步成長。
3. non-GAAP毛利率回到12.5%以上，營益率≥11%。
4. 存貨增速低於營收，營業現金流與FCF恢復。
5. NPO或OCS開始被公司獨立量化，而非只描述pipeline。

## 下修與賣出條件

1. 毛利率跌破11.8%或營益率跌破10%。
2. 存貨繼續年增50%以上，但營收增速跌破25%。
3. 四大客戶中任一家營收占比或訂單顯著下降，且新客戶無法補上。
4. Building 10延遲、良率爬坡不順，或CapEx再次大幅上修。
5. 連續兩季FCF為負、應收帳款增速持續快於營收。
6. 客戶forecast轉弱，2027能見度無法轉成firm orders。
