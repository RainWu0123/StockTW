# 技術分析體系筆記＋回測驗證

**資料截止**: 2026-08-22
**來源**: 學吧 LearningPa 技術分析篇（YouTube 播放清單）＋ TWSE 官方日K回測（2330/2454/2308，各 236 天）

---

> **TL;DR：教科書教的「死亡交叉要賣」「RSI超買要賣」在 AI 強勢股上是錯的。回測發現布林下軌是唯一三檔都100%勝率的買進訊號，站上MA20是可靠的趨勢確認。技術分析不是看圖說故事，是用歷史數據找出有統計優勢的訊號。**

## 一、六大核心指標體系

### 1. K棒（一切指標的源頭）

| 要素 | 說明 |
|---|---|
| 四個點 | 開盤價、收盤價、最高價、最低價 |
| 紅K | 收盤 > 開盤（台股漲） |
| 綠K/黑K | 收盤 < 開盤 |
| 十字線 | 開盤 = 收盤（多空拉鋸，變盤前兆） |

**關鍵型態**：
- **吞沒型態**：第二根長黑K完全吃掉前一天紅K → 賣出訊號（需配合成交量放大）
- **錘頭線**：下影線很長 → 可能見底反彈
- **上吊線**：高檔出現長下影線 → 可能反轉下跌

### 2. 移動平均線（MA）

| 參數 | 用途 | 台股常用 |
|---|---|---|
| MA5 | 週線，短線方向 | 日線操作 |
| MA20 | 月線，波段趨勢 | 波段持有判斷 |
| MA60 | 季線，中期趨勢 | 中期多空分界 |
| MA240 | 年線，長期牛熊 | 長期趨勢確認 |

**黃金交叉**：短期MA由下往上穿越長期MA → 買進訊號
**死亡交叉**：短期MA由上往下跌穿長期MA → 賣出訊號
**多頭排列**：MA5 > MA10 > MA20 > MA60 → 強勢上升趨勢
**空頭排列**：MA5 < MA10 < MA20 < MA60 → 下降趨勢

### 3. KD 隨機指標

| 區間 | 意義 | 操作建議 |
|---|---|---|
| K < 20 | 過冷區 | 反彈機率提升，找買點 |
| K > 80 | 過熱區 | 回檔風險升高，注意賣點 |
| 黃金交叉 | K 由下穿越 D | 短線轉強 |
| 死亡交叉 | K 由上穿越 D | 短線轉弱 |
| 背離 | 價格創新高但KD沒跟上 | 反轉警訊 |

**鈍化**：強勢行情中 KD 可長時間停留在極端區，此時指標失效。

### 4. RSI 相對強弱指標

- RSI > 70：超買（漲太快）
- RSI < 30：超賣（跌太深）
- RSI = 50：中性
- 配合背離使用效果更好

### 5. MACD 平滑異同移動平均線

| 元素 | 意義 |
|---|---|
| DIF（快線） | EMA12 - EMA26 |
| MACD（慢線） | DIF 的 9 日 EMA |
| OSC（柱狀圖） | DIF - MACD |
| 黃金交叉 | DIF 上穿 MACD 且 OSC 由負轉正 → 多頭動能增強 |
| 死亡交叉 | DIF 下穿 MACD → 空頭動能增強 |
| 零軸之上 | DIF > 0 表示處於多頭格局 |

### 6. 布林通道（Bollinger Bands）

| 元素 | 意義 |
|---|---|
| 中軌 | 20 日均線（趨勢脊椎） |
| 上軌 | 中軌 + 2 倍標準差（壓力） |
| 下軌 | 中軌 - 2 倍標準差（支撐） |
| 壓縮（bandwidth < 8%） | 盤整蓄力，暴風雨前的寧靜 |
| 觸及上軌 | 漲太多，可能回檔 |
| 觸及下軌 | 跌太深，可能反彈 |

**三大陷阱**：
1. 碰到上軌就賣 → 強勢股會沿著上軌走（鈍化）
2. 碰到下軌就買 → 下跌趨勢中的下軌是溜滑梯不是地板
3. 忽略中軌方向 → 中軌向下時碰到上軌只是逃命波

## 二、回測驗證結果

### 回測設定
- 標的：台積電(2330)、聯發科(2454)、台達電(2308)
- 期間：各約 236 個交易日（近一年）
- 方法：訊號觸發後持有一天至十天，統計勝率與平均報酬

### 高勝率買進訊號（勝率 ≥ 75%，觸發 ≥ 3 次）

| 訊號 | 台積電 | 聯發科 | 台達電 | 平均報酬 |
|---|---|---|---|---:|
| **觸及布林下軌** | 100%（5次） | 100%（7次） | 100%（6次） | +6.4~9.3% |
| **站上MA20** | 66.7%（12次） | 80.0%（5次） | 100.0%（9次） | +2.7~7.6% |
| **布林通道壓縮** | 76.5%（17次） | 83.3%（6次） | — | +3.1~4.0% |
| KD低檔黃金交叉 | 100%（1次） | 66.7%（3次） | 100%（3次） | +2.1~9.4% |
| RSI<30超賣 | — | 100%（2次） | 100%（1次） | +9.0~10.4% |
| MA5黃金交叉MA20 | 71.4%（7次） | 75.0%（4次） | 40% | +2.9~5.2% |
| 多頭排列啟動 | 62.5%（8次） | 75.0%（8次） | 57.1%（7次） | +0.6~4.2% |

### 低勝率／反直覺發現

| 訊號 | 問題 | 教科書說法 vs 回測結果 |
|---|---|---|
| KD高檔死亡交叉 | 勝率僅50%，平均報酬仍為正 | 教科書說要賣；實際上強勢股KD死亡交叉只是洗盤 |
| MACD死亡交叉 | 台達電勝率僅25%、報酬-1.55% | 教科書說空頭動能增強；實際上多頭股MACD死叉常是假訊號 |
| RSI>70超買 | 勝率56~70%但平均報酬為正 | 教科書說超買要賣；實際上RSI可以鈍化很久，超買不該急著賣 |
| 觸及布林上軌 | 勝率50~70%但平均報酬不穩定 | 教科書說壓力；實際上沿上軌走的強勢股反而最強 |

### 核心教訓

1. **均值回歸類訊號（布林下軌、乖離率<-7%）在大型權值股上最可靠**
2. **動能衰竭類訊號（KD/MACD死亡交叉）在 AI 強勢股上是假訊號**
3. **突破確認類訊號（站上MA20、黃金交叉）中等可靠但需要量能配合**
4. **任何單一訊號都不夠，至少需要兩個以上共振才有意義**

## 三、可操作的量化規則

### 短線買進條件（需同時滿足 ≥ 2 項）

1. 觸及布林下軌且出現紅K止跌
2. KD 在低檔（<25）黃金交叉
3. 站上 MA20 且成交量放大
4. 乖離率 < -5% 後回升

### 短線避險條件（任一滿足即提高警覺）

1. 布林通道壓縮後突然擴張但方向不明確
2. 成交量萎縮至均量的 70% 以下且跌破 MA20
3. 乖離率 > +10%（過度延伸）

### 長線趨勢確認

1. MA5 > MA10 > MA20 多頭排列
2. MACD DIF 在零軌之上
3. 每季營收年增 > 15%
4. ROE > 15%
