# 買了最貴的 GPU，然後讓它閒著

2026 年全球科技巨頭在 AI 基礎設施上的資本支出預計超過一兆美元。黃仁勳說到 2030 年這個數字會變成四兆。華爾街一邊照單全收，一邊不太舒服，因為他們記得光纖泡沫。

但真正值得問的問題不是「會不會泡沫」，而是一個更樸素的問題：花四百萬美元買一台 NVIDIA GB200 NVL72 機櫃，結果 GPU 有一半時間在等，不覺得浪費嗎？

卡內基梅隆大學最近對 756 塊 GPU 做了 31 天的細粒度遙測，涵蓋 A100 到 B200 的六代產品。結論很直接：近 20% 的執行時間和 11% 的能耗，被花在一種叫「execution-idle」的狀態上，就是 GPU 看起來在跑，實際上在等東西。推理場景更嚴重，Azure Code 負載有 65% 的能耗消耗在這種空轉上，OpenAI 的 Chat 類請求也有 52%。

Cast AI 的 2026 年 Kubernetes 報告給了更狠的數字：企業 GPU 平均利用率只有 5%。

這不是「卡不夠」的問題，是「卡用不好」的問題。而這個缺口，正在催生一個千億級別的市場。

## GPU 為什麼會閒著

要理解這件事，得先看 AI 基礎設施其實有四層。最底層是電力和散熱，決定 GPU 能不能穩定跑。第二層是硬體本身，GPU、高頻寬記憶體、互聯。第三層是系統軟體，CUDA、編譯器、算子庫。最上面是服務編排，推理引擎、調度器、請求路由，vLLM 和 SGLang 就在這一層。

底下兩層是硬問題，改造週期以年計，而且優化空間正在見頂。你不可能每個月換一批晶片，也不可能每週重拉一條電網。上面兩層是軟問題，本質上是工程和算法，優化之後能帶來數倍性能提升，而且週期是週和月。

行業的注意力正在快速上移。一台 400 萬美元的機櫃，如果軟體棧沒做好調度，利用率只有 50%，等於 200 萬美元以電費、折舊和機會成本的形式被白燒。反過來把利用率從 50% 推到 90%，效果等於憑空多出一台機櫃。

邏輯就這麼簡單：硬體已經貴到一個程度，軟體層每一次優化都變成直接的金錢問題。

## 四個問題，四種答案

具體怎麼把 GPU 榨滿？行業目前的努力可以歸結為四個問題。

**哪些計算不用重做？** 大模型推理裡有個很傻的事實：同一段文字被反覆餵給模型時，每次都從頭算。在 Agent 工作流裡，同一段工具描述可能被調用幾十次，每次都從零開始，業界叫它「推理稅」。Anthropic 做了一版優化，直接把成本砍了 90%。背後的核心思路是 KV Cache 複用，把算過的東西存下來下次直接用。SGLang 更進一步，用一種叫 RadixAttention 的技術把 KV Cache 變成跨請求、跨機器的共享資源，共享前綴的請求像家族樹一樣共用枝幹，只在內容分叉時各長各的。這在 Agent 越來越多共享 system prompt 的趨勢下，效果持續放大。

**哪些等待可以消除？** 推理有兩階段：讀入（prefill）和生成（decode），過去塞在同一張 GPU 裡混合跑，互相等。現在的做法叫 PD 分離，把兩個階段拆到不同 GPU 上各跑各的。DeepSeek 在做，NVIDIA 自己的分散式框架 Dynamo 也把 PD 分離放核心位置。加上 Continuous Batching 把排隊制改成隨時上下車的公車制，吞吐量能提升 2 到 4 倍。

**哪些算力沒吃滿？** H100 的 Tensor Core 算力比 A100 翻了好幾倍，但推理性能沒跟上，因為 GPU 大量時間花在數據搬運而非計算。兩個方向：低精度計算用更小的數據格式存模型權重和 KV Cache，相當於多釋放一倍算力；投機採樣用小模型先「猜」幾個字再讓大模型一次性驗證，最佳情況生成速度提升 2 到 3 倍。

**哪些資源沒協同？** 強化學習後訓練把推理、評估、參數更新三種完全不同的計算揉在一起循環跑，傳統訓練框架讓它們在同一批 GPU 上互相等。RadixArk 的 Miles 框架把訓練和推理放在同一個系統裡一起調度，形成更高效的後訓練閉環。這不只是工程優化，是在賭 RL 後訓練會成為主流。

## SGLang 為什麼值得 NVIDIA 下注

SGLang 部署在全球數十萬張 GPU 上，每天為 Google、Microsoft、NVIDIA、Oracle、AMD、Nebius、LinkedIn、xAI 生成數兆 token。它在 2026 年初正式從開源社區孵化出商業公司 RadixArk，種子輪 1 億美元，估值 4 億，Accel 和 Spark 領投。

投資人名單本身就是一封信：NVIDIA 的創投部門 NVentures、AMD、聯發科、Databricks 都在。個人天使更誇張，Intel CEO 陳立武、Broadcom CEO 陳福陽、OpenAI 共同創辦人 John Schulman、PyTorch 創辦人 Soumith Chintala、Hugging Face 共同創辦人 Thomas Wolf。

NVIDIA 投一家跟自己軟體棧競爭的開源引擎，不是犯傻。硬體廠商心裡很清楚：他們需要買 GPU 的人有最好用的軟體跑，不管誰寫的。SGLang 已經變成硬體 day-0 支援的預設基準，AMD 和 NVIDIA 發新硬體時直接用 SGLang 跑效能數字。某種程度上，SGLang 是 AI 硬體的性能測試工具。

這個位置的戰略價值，比營收數字重要得多。

## 推理賽道的估值光譜

同一段時間，推理賽道上的估值在狂飆。

Fireworks AI 在 2026 年 7 月完成 15 億美元 Series D，估值 175 億，年化營收突破 10 億，日 token 量 40 兆。七個月前它的估值還只有 40 億。Baseten 更誇張，五個月內從 50 億翻了三倍到 110-130 億。vLLM 商業化的 Inferact 種子輪 1.5 億，估值 8 億，a16z 和 Lightspeed 領投。

但這四家不是同一回事。Fireworks 和 Baseten 是推理服務平台，直接賣 token 給企業，抽得多但要承擔硬體成本和運維。RadixArk 和 Inferact 是推理引擎，賣基礎設施軟體，抽得少但槓桿高，一座引擎跑在數十萬張別人的 GPU 上。

這個結構跟支付產業很像。美國運通每 100 美元交易抽 2.24 美元，什麼都自己扛。Visa 只抽 0.23 美元，放款和客服全交給銀行，結果營業利益率高出一截。抽得多不一定留得多，少做一些事，有時反而能創造更好的商業模式。推理引擎賭的就是同一件事：不碰硬體、不碰客服、只做連接層，讓別人來扛重活。

## 這個賽道能撐多久

目前为止，这个故事是完整的。但有几个东西正在变化。

第一，云端巨头在自建。OpenAI 的推理团队已经堆了 200 多人，Anthropic 的 infra 队伍从极度不稳定做到趋于稳定，Q2 已经盈利。他们有钱有人，理论上可以把开源引擎绕过去。如果哪天 OpenAI 或 Anthropic 公开宣佈内部引擎取代了开源依赖，SGLang 和 vLLM 的商业逻辑就会被挑战。

第二，NVIDIA 自己有 Dynamo。Dynamo 是 NVIDIA 的分散式推理框架，已经把 PD 分离放核心。如果 Dynamo 功能追上 SGLang 的硬體支援和模型覆盖广度，开源引擎的 day-0 优势就会弱化。目前 SGLang 的社群生态和硬体覆盖度仍有壁垒，但这个壁垒不是永久的。

第三，开源双胞胎在收敛。vLLM 和 SGLang 的功能越来越像。如果合并或一方胜出，另一方的商业化逻辑会被质疑。turion.ai 的分析指出两个项目正在 convergence，这既可能是生态整合的好事，也可能是竞争白日化的信号。

还有一层更远的隐忧。人现在选推理引擎靠品牌、社群和习惯。但 AI Agent 自动部署模型的时候，可能只看三个数字：每 token 成本、每秒 token 数、首 token 延迟。到那个时候，推理引擎的品牌忠诚度会弱化，竞争回归硬指标。如果 AI Agent 能自己切换引擎，这一层的定价权会被压到接近边际成本，变成像 DNS 一样的基础设施，不可或缺但难以溢价。

## 对台股意味着什么

这份研究的价值不在买哪档，而在一个观察框架：**AI 投资的下一阶段不是谁卖最多卡，而是谁把卡用得最满。**

台积电（2330）的方向偏多，因为 AI Infra 需求带动更多 GPU 出货，先进制程需求持续。但利用率提升也意味着不需要买那么多卡，这是双刃剑，不能只看一边。

散熱族群（3017 奇鋐、3653 健策）偏多。GPU 功耗不会因为利用率提升而下降，一个跑满的机柜跟一个跑半满的机柜产生的热量是同一回事。散热需求跟随 GPU 出货成长，不会被推理引擎优化抵消。

伺服器代工（2382 廣達、6669 緯穎、2356 英業達）偏多但要注意规格变化快。推理需求带动出货，但 PD 分离等新架构在改服务器配置方式。

创意（3443）需要观察。推理加速芯片设计需求在，但被开源引擎可能取代部分 IP 价值。

什么时候该警觉：NVIDIA 或 AMD 宣佈自建推理引擎成为预设，绕过开源生态；CMU 式遥测研究显示 GPU 利用率已被系统性拉到 85% 以上，效率红利见顶；Fireworks ARR 成长从 5 倍降至 2 倍以下，赛道降温。

## 底牌

RadixArk 的创办人说了一句很有野心的话：「以后没有 Frontier Lab 这个词，因为人人都可以做 Frontier Lab。」

这句话的底层逻辑是：当 AI Infra 变成公共品，人人都能调用的基础设施，任何有想法的人都能做前沿模型。推理引擎就是那个公共品的提供者。

这跟 Visa 的逻辑恰好相反。Visa 是把网络效应做到极致收过路费。RadixArk 是把基础设施做到极致让过路费消失。哪个能成，不知道。但这个赛道的方向是对的：全世界花了几千亿美元买 GPU，不可能永远接受它一半时间在闲着。
