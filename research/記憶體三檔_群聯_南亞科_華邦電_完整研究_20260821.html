群聯（8299）：低成本NAND庫存創造暴利，AI儲存能否接棒才是估值核心

結論：以2026年8月20日收盤1,995元為基準，我給群聯12個月目標價3,000元，合理區間2,700～3,300元，判斷HOLD／偏多。這是將官方資料推導的未來四季稀釋EPS約300元乘以10倍，而非把Q2高達65.3%的毛利率直接永久化。群聯品質是三檔最佳，但917.9億元存貨與負營業現金流讓它不能套純IC設計估值。[20][21][17]

上半年營收1,088.55億元、EPS 187.43元，董事會配發60元現金股利，配發率約32%。[2]

Q2毛利率遠高於群聯歷史常態，主要來自：

  1. NAND價格上漲，低成本庫存形成巨大價差。
  2. 企業級SSD與AI儲存產品占比提高。
  3. 控制器、韌體與模組整合，讓群聯可把NAND加工成高附加價值方案。
  4. 市場供給吃緊，群聯有能力把有限NAND配置給高毛利客戶。

但管理層也承認，隨新採購NAND成本提高，毛利率必然正常化。Q2 EPS不能直接乘四。[1][3]

商業模式：控制器只是核心，收入靠完整儲存方案放大

群聯的價值鏈是：

向NAND原廠／通路採購wafer
→ 加入自研控制器、韌體與驗證
→ 製成企業SSD、嵌入式、工控、車載及AI系統模組
→ 取得高於純晶圓／低階模組的溢價

它的護城河不是「持有很多NAND」，而是：

  • 控制器與韌體共同設計。
  • 長期design-in與客製化驗證。
  • 能將不同NAND顆粒轉成穩定產品。
  • 在供貨吃緊時仍能保證企業客戶長期供應。
  • 從Boot Drive、Main Drive延伸到AI Data Platform與aiDAPTIV。

若只靠庫存價差，群聯終究是週期股；若企業SSD與AI資料平台能提高正常化毛利率，它才有資格獲得比傳統模組廠更高的估值。

AI營收已達38%，但真正的新平台收入仍小

公司法說指出，AI Ecosystem Solutions約占Q2營收38%，企業級主硬碟占整體營收30%以上；AI Networking單季新增6個design wins，PCIe Gen6企業SSD已有客戶等待執行。[1]

但必須拆開：

  • 企業SSD、Boot Drive、Main Drive：已是實質營收。
  • aiDAPTIV／AI Data Platform：已商轉，但目前收入仍小。
  • 醫療、銀行、中小企業案例：代表產品驗證，不等於已形成大型年約收入。

因此，我不把「AI平台」當成Q2暴利的主要來源；目前主要獲利仍是NAND上漲＋低成本庫存＋高價值SSD。

917億元庫存是護城河，也是最大地雷

Q2存貨917.92億元，存貨周轉天數297天，雖低於Q1的315天，仍高於去年同期221天；現金與流動金融資產約337.99億元。[3]

群聯認為這些庫存主要對應CSP、OEM、企業級與工控等非零售客戶，部分專案供貨週期長達24個月。6、7月又投入逾4.5億美元購買低於原廠合約價的NAND。[3]

多頭版本：

低價取得NAND
→ 鎖定未來長約供貨
→ NAND續漲＋企業SSD放量
→ 庫存轉成高毛利營收

空頭版本：

NAND供應恢復／價格反轉
→ 客戶延後拉貨
→ 917億元庫存跌價
→ 毛利率與營業現金流同步崩落

後續不能只看EPS，要盯存貨金額、周轉天數、跌價損失、短期借款與營業現金流。

現金流與稀釋：財報獲利尚未轉成股東現金

2026H1稅前淨利489.73億元，但存貨增加575.46億元、應收帳款增加247.77億元，營業現金流反而為負148.73億元；期末315.47億元現金主要受312.5億元公司債支撐。基本EPS 187.43元，稀釋EPS177.01元，差距約5.6%；另有私募普通股上限1,800萬股與可轉債潛在稀釋。[21]

Q2有89.6%營收來自含NAND的模組，控制器僅6.1%。AI Ecosystem占38%同時包含eSSD、aiDAPTIV、AI PC、Networking與Boot Drive，不能把38%全部當成高毛利企業SSD。公司未拆分eSSD、軟體平台與各產品線毛利率。[20][21]

另有部分權益法投資未經獨立會計師核閱，上半年權益法利益約63.42億元、約貢獻EPS 24.87元。估值時不把這部分視為永久性本業獲利。[21]

同業財報：NAND上行是真的，但已不是低預期階段

Micron FQ3 NAND ASP季增約85%、NAND營收99億美元；SK hynix Q2 DRAM與NAND均大幅漲價；Samsung也表示server DRAM、eSSD與HBM需求讓市場維持供不應求。[14][15][16]

這證明群聯的需求與價格不是自說自話。但當原廠毛利率逼近歷史極端、所有市場參與者都知道缺貨時，後續股價更看「漲幅是否再超預期」，而不是只看價格仍在漲。

法人報告：共識高度分歧

  • FactSet 13位分析師：2026 EPS中位數359.86元、2027中位數249.84元，目標價2,998元；2027 EPS最低127.58元、最高589.42元，分歧極大。[4]
  • 未揭露本土法人：2026／2027 EPS 401／336.12元，因NAND漲幅收斂把目標價由3,200降至2,700元，2027給8倍PE。[5]
  • 其他公開報告區間約2,950～4,000元，但多數建立在2026 EPS 360～415元與高毛利延續。

目標價分歧的根源不是AI需求，而是2027低成本庫存紅利消失後，正常化EPS到底是150、250還是400元。

南亞科（2408）：DRAM價格創造近80%毛利率，最大風險是把高峰當常態

結論：以2026年8月20日收盤517元為基準，我把南亞科12個月目標價由初版600元下修至380元，合理區間350～420元，判斷REDUCE／不追價。正式核閱財報顯示私募後股數增加約10.2%，而517元已接近需要未來12月EPS 65～75元與長時間高毛利的Bull情境。[22][23][18]

先糾正定位：南亞科不是HBM3E／HBM4核心供應商

南亞科主力仍為DDR5、LPDDR5／5X、DDR4、LPDDR4／4X、DDR3等DRAM。公司已增加AI基礎設施與伺服器產品，H1相關營收占比超過20%，並發展客製化AI、WoW與先進封裝合作，但目前不能把它直接等同SK hynix、Micron、Samsung的HBM供應商。[6]

正確投資論點是：全球三大廠把先進產能與資本支出優先投向HBM、server DRAM與高階產品，排擠傳統DRAM供給，南亞科因此享受DDR4／LPDDR／DDR5價格與產品組合紅利。

所以後續最重要的不是單月營收創高，而是ASP增幅是否由+60%降到+20%、持平，最後轉跌。

同業財報確認超級週期，但也顯示獲利率已在高峰區

Micron FQ3 DRAM ASP季增約60%、NAND ASP約85%，毛利率約85%；SK hynix Q2營益率76%；Samsung Memory也創營收與營業利益新高，並預期H2 server DRAM、eSSD與HBM持續供不應求。[14][15][16]

這支持南亞科Q3價格仍強。但當全球原廠毛利率都在70%～80%以上，市場已經知道供應短缺，任何「漲幅低於預期」都可能被當成週期見頂。

LTA提高能見度，不等於鎖定毛利率

公司正與客戶把單季合約拉長為年度甚至多年LTA；市場報導稱LTA覆蓋可能接近一半產能，且AI相關占比將提高。[9]

但公開資訊未完整揭露：

  • 固定價與浮動價比例。
  • Take-or-pay條款。
  • 客戶取消或重談條件。
  • 每年價格重設方式。

LTA可以保出貨，不一定保79.5%毛利率。若合約跟隨市場價格調整，DRAM轉跌時EPS仍會下降。

5A新廠是長期升級，也是3466億元資本豪賭

董事會把2026資本支出上限由520億提高至697億元；2026～2029年5A新廠第一階段資本支出上限3,466億元，目標月產能35,900片，最終規畫45,000片，導入1B／1C／1D／1E與EUV。2027下半年投片，2028月產30,000片，2029提高至35,900片。[7]

正面：

  • 補上先進製程與成本競爭力。
  • 提高DDR5、LPDDR5與客製化AI產品能力。
  • 產能開出時間晚，短期不會立刻破壞供需。

風險：

  • 大額設備預付款、折舊與EUV學習曲線。
  • 2028～2029若產業供給同步開出，可能踩到週期下行。
  • 新廠還沒營收前，現金流與ROIC先承壓。

公司法說揭露全產能投資估計約4,800億元；董事會後續核准的3,466億元是5A新廠階段性資本支出上限，兩者口徑不能混為同一個總額。[7][23]

現金、私募與稀釋

華邦電（2344）：利基記憶體進入高毛利週期，但別把它當HBM替代品

結論：以2026年8月20日收盤176.5元為基準，我把華邦電12個月目標價由初版235元下修至185元，合理區間170～200元，評價NEUTRAL。初版2027 EPS 45元沒有正確納入47.2億股完全稀釋股數，數學上過度樂觀；官方分部模型的Base EPS約15.1元、Base價182元，機率加權約185元。[25][11][19]

正確定位：AI外溢受惠，不是AI伺服器主記憶體供應商

華邦電主要業務：

  • CMS（Customized Memory Solution）：Specialty DRAM、DDR3／DDR4等客製化記憶體。
  • Flash：NOR Flash、SLC NAND與Code Storage Flash。
  • Logic IC：主要包含子公司新唐等邏輯事業。
  • 新產品：CUBE、Si-Cap、先進16nm DRAM。

它不是HBM大廠，也不是AI GPU主記憶體供應商。真正受惠路徑是：三大記憶體廠把先進產能轉去HBM與server DRAM，造成利基DRAM、NOR、SLC NAND供給收縮；同時AI交換器、網路設備、車用與工控提高記憶體容量。[10][11]

記憶體本業Q2營收517億元、毛利率70.3%、營益率56.9%、稼動率100%。[10][11]

CMS位元出貨季減約低十位數，但ASP翻倍，與南亞科相同，Q2營收爆發主要靠價格而非出貨量。Flash則同時有量價改善。

因此合併估值不能只看記憶體70.3%毛利率；新唐與邏輯事業會稀釋整體毛利，也提供週期分散。

NOR與SLC NAND是華邦最難被簡化的優勢

  • NOR Flash服務程式碼儲存、車用、工控、網通與高容量AI交換器。
  • SLC NAND強調耐用性與可靠度，24nm、32nm產品比重提高。
  • Specialty DRAM客戶規格分散、驗證期長，價格敏感度低於完全標準化商品。
  • AI伺服器機架與交換器提升NOR容量，由512Mb、1Gb到2Gb以上，推升單機價值量。

這讓華邦電的正常化獲利理應比純消費記憶體廠穩，但仍無法消除DRAM／Flash價格週期。

16nm與89B擴產：2027先吃製程紅利，2029才有大量新產能

16nm產能擴充按計畫進行，2027開始顯著貢獻；高雄產能目標由月產1.5萬片提高至2.4萬片，良率由約88%往90%提升。Module B預計2027動工、2029量產，導入EUV與14nm／12nm製程。[11]

2026 CapEx預估約395億元，上半年約70億元，支出高峰仍在後面。

正面：

  • 製程微縮提高每片晶圓bit產出與成本競爭力。
  • 大量新增產能要到2029，2027供需仍可能偏緊。
  • LTA提前鎖定2029／2030客戶需求。

風險：

  • 高雄新廠、EUV與先進製程折舊。
  • 16nm爬坡若良率不如預期，成本效益延後。
  • 大量舉債或發債會提高財務費用。

存貨與現金流

Q2存貨約257.87億元，年增約19%，但相對營收增速溫和；Q1營業現金流123.66億元，顯示獲利開始轉成現金。公司為擴產已增加融資與公司債，不能只看單季EPS。[11]

後續應盯：營業現金流、CapEx、淨負債、存貨周轉、新唐現金流與合併自由現金流。

H1營業現金流356.72億元，扣除設備支出80.88億元後簡化自由現金流約275.84億元；但應收帳款由160.71億元升至374.39億元，備抵損失也提高，後續需檢查營收停止成長時應收款是否仍增加。[25]

華邦持有新唐48.97%但仍具控制力，因此新唐全額併入營收，歸母利益只按實際權益分配。新唐Q2營收79.41億元、營業損失3.33億元、EPS負0.58元，短期不是獲利引擎。[25][26]

海外可轉債若全數轉換，股數由約45億股升至47.2億股、稀釋約4.9%；本估值採完全稀釋股數。這是初版EPS推估需要下修的主因。[25]

同業交叉驗證

Micron、SK hynix、Samsung Q2／FQ3均確認server DRAM、eSSD、HBM需求強，供給受限，DRAM與NAND ASP大幅上升。[14][15][16]

對華邦的意義不是它會拿到HBM訂單，而是大廠產能轉移讓Specialty DRAM、NOR、SLC NAND的供給更緊。若三大廠重新回頭擴產傳統產品，華邦的利基溢價會收縮。

操作與否決條件

  • 170～190元：基準合理區，不追價。
  • 140～150元：接近Base打八折，才有較明顯安全邊際。
  • 200～230元：已開始交易Bull機率。
  • 297元以上：超過官方分部模型Bull價，需新的營收與獲利證據。

否決條件：CMS ASP季增降至個位數後轉負、Flash價格轉跌、16nm良率停滯、新唐明顯拖累合併獲利、CapEx與負債上升但營業現金流不跟、NOR市占下降、LTA未轉成實際出貨。
