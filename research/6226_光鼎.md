# 一句話結論

光鼎本質上仍是 **LED 元件與模組廠**，正在用高功率 LED 模組與 IGBT／SiC MOSFET 建立第二成長曲線。2026 上半年毛利率約 30%、稅後小幅轉盈，代表成本與產品組合改善已發生；但功率半導體目前約只占營收 1%，本業仍未穩定獲利，因此現在更像「轉機驗證中的高波動題材」，不是已完成轉型的功率半導體公司。

## 公司在做什麼

### 1. 傳統核心：LED 元件封裝

公司製造、加工與銷售各種 LED、LED 顯示器與相關光電產品，產品包括 SMD/PLCC、Lamp、Display、UVC/UVA、不可見光與感測器件。主要製造基地在中國南京、連雲港與緬甸仰光。

這類業務的問題是標準化程度高、價格競爭激烈，單靠 LED 元件數量成長很難帶來高獲利。因此公司把既有封裝能力向模組與成品延伸，例如照明、家電顯示、電競機箱柔性光源、充電樁顯示與工控面板。

### 2. 轉型方向：高功率 LED 模組

光鼎試圖從「賣 LED 元件」往「依客戶需求整合光學、電路、機構與散熱」移動。價值提升來自客製化、模組化與成品整合，而非單純封裝數量。

### 3. 新事業：功率半導體

公司自 2022 年布局功率半導體，產品路線包括：

- 第七代微溝槽 IGBT 離散元件與功率模組。
- 2026 年推出低溫度係數導通電阻的 SiC MOSFET，主打高溫、高負載情境。
- 應用鎖定伺服馬達、工業電源、UPS、太陽能逆變器、儲能、電網與 EV 快充。

目前超過九成相關訂單集中印度市場，仍在客戶驗證與導入階段。公司說法是功率半導體短期營收貢獻低，中期放大營收與毛利，長期希望占總營收 10%。這是管理層目標，不是已確認的訂單或財測。

## 財務與營運轉折

### 2026 上半年

| 指標 | 2026H1 |
|---|---:|
| 營收 | 3.269 億元 |
| 年增 | 約 4.0% |
| 毛利 | 1.001 億元 |
| 毛利率 | 約 30.6% |
| 營業利益 | -1,344 萬元 |
| 稅前淨利 | 1,000 萬元 |
| 稅後淨利 | 358 萬元 |

資料來自公司 2026/08/06 公告之 2026H1 合併財報。季度資料顯示 Q2 營收 1.752 億元、毛利率約 31.0%、營業利益仍為負，但稅後淨利 242 萬元。這代表目前的「轉盈」還帶有業外因素，不能直接等同本業已翻正。

### 解讀

- **正面**：毛利率由低檔回到約 30%，產品組合、緬甸廠效益與成本控制確實改善。
- **限制**：營收只小幅成長，營業利益仍虧損，表示固定費用、研發與管理費尚未被新產品規模攤薄。
- **最重要驗證**：未來 2～4 季功率半導體營收占比是否從約 1%提升，且營業利益能否連續轉正。

## Driver Chain

### LED 模組

產品由元件 → 客製模組/成品
→ 單價與毛利提升
→ 在同樣營收下改善毛利
→ 但需要客戶導入與持續出貨驗證。

### 功率半導體

印度客戶送樣與認證
→ IGBT/SiC MOSFET 導入逆變器、儲能、伺服器或工業電源
→ 功率半導體營收占比提升、產品組合改善
→ 毛利與營業利益改善
→ 市場才可能從 LED 廠重新評價為功率元件轉機股。

目前鏈條已確認到「產品推出、客戶驗證、訂單能見度到年底」；尚未確認「大規模量產、實際營收占比與本業獲利」。

## 競爭位置

公司不是以晶圓製造或最先進功率元件製程取勝，主要是元件設計、封裝、模組應用與客戶導入。功率半導體的競爭對手包含 Infineon、onsemi、Fuji Electric 與中國功率元件廠。相較國際大廠，光鼎的機會是利基市場、價格與客製服務；弱點是規模、品牌、可靠度認證與客戶黏著度仍不足。

## 估值與市場已反映

2026/08/21 外部報價資料顯示股價約 21.20 元、每股淨值約 10.85 元，約 1.95 倍 PB；公司近四季仍虧損，本益比不適用。這種公司不應用 PE 定價，現階段比較適合用 PB 加上轉型成功機率，或等本業獲利連續轉正後再切換至正常化 EPS。

股價若已提前反映「功率半導體占比提升、2026/2027 獲利轉折」，後續需要實際營收與毛利率兌現，不是再增加題材敘述。

## 風險與否決條件

1. **功率半導體無法量產**：印度客戶認證延後，或 2027 年營收占比仍停留在低個位數。
2. **毛利率回落**：連續兩季低於 28%至30%區間，代表模組化或功率元件 mix 未能改善。
3. **本業未轉正**：營收成長但營業利益仍持續為負，顯示新事業只增加費用沒有增加貢獻。
4. **客戶集中**：功率半導體超過九成訂單集中印度，單一市場與認證延誤風險高。
5. **現金流壓力**：轉型需要研發、設備與庫存投入；須追蹤營業現金流是否連續改善。

## 商業解碼：光鼎真正賣的是「導入與封裝」，不是 SiC 故事本身

### 每 100 元如何流動

目前營收約九成仍來自 LED 封裝與模組、功率半導體約 1%（公司／媒體揭露口徑，需持續核對）。客戶付錢給光鼎的主要是 LED 元件、客製模組、封裝與產品導入；光鼎再承擔晶圓／元件採購、封裝製程、良率、認證、庫存與研發費用。SiC 的市場價值只有在客戶驗證通過、量產出貨後，才會從研發費變成營收與毛利。

### 四種密度

| 維度 | 判斷 |
|---|---|
| 收入密度 | LED 元件量大但單價與議價權較弱，模組與功率元件單價較高但尚未放量 |
| 毛利密度 | H1 毛利率約 30.6%，但營業利益仍負，表示費用與規模尚未被吸收 |
| 資本密度 | 需要研發、測試、認證、庫存與海外製造配置；目前非純資產輕模式 |
| 風險密度 | 功率半導體超過九成相關訂單集中印度，認證、關稅、客戶集中與量產良率風險高 |

### 護城河與競爭取捨

光鼎的可辯護性來自封裝經驗、客製模組與客戶導入，而不是與 Infineon、onsemi 比拼晶圓製程規模。它可以用價格、彈性與利基市場切入，但要建立真正護城河，必須看到可靠度認證、重複訂單、良率與客戶轉換成本。若 SiC 只是送樣，研發費與庫存是護城河維護成本；若量產後毛利與現金流同步上升，才是健康投資。

### 結構性權力轉移

AI 伺服器、儲能與 EV 提高功率密度
→ 客戶尋找更高效率的 IGBT／SiC 元件
→ 光鼎以利基市場與客製導入切入
→ 但上游晶圓／品牌大廠仍掌握核心製程與認證標準
→ 光鼎的議價權取決於是否成為客戶合格供應商，而非題材熱度。

## 研究判斷

- 研究類型：高波動轉機股。
- 目前成熟度：60，已知道公司做什麼與轉型方向，但缺少功率半導體實際營收、客戶名單、毛利拆分與本業連續獲利證據。
- 判斷：**HOLD／觀察，不追題材**。若要升級為可配置標的，至少等待功率半導體營收占比上升、營業利益連續轉正、以及印度客戶量產訂單被公司公告或財報確認。
