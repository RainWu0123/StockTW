# 《一綺聊股》本週最大利空與記憶體、無人機、漲價題材輪動

> **一句話結論：** 影片不是在找長期投資標的，而是在做一週盤前資金輪動地圖。最有用的部分是把「記憶體基本面、漲價題材、國防預算、法說催化劑、處置與周轉率」放在同一個短線框架；但多數個股結論仍屬技術面與事件交易，不宜直接升格為基本面投資建議。

- 影片：一綺聊股，2026年8月中旬發布
- 來源：使用者提供之 YouTube 影片逐字內容[1]
- 研究日期：2026-08-17
- 影片可信度：市場盤面整理 7/10，個股長線判斷 5.5/10

## 一、影片在講什麼

影片主軸有五條：

1. NVIDIA財報是AI與市場情緒的短線驗證點。
2. 景碩、星星、台燿、川湖、健策、全新等處置股出關，可能帶來流動性與資金重新分配。
3. 國防無人載具預算634億元通過，軍工與無人機族群出現政策催化劑。
4. 南亞CCL漲價、石英元件、記憶體供應緊張，構成漲價與缺貨題材。
5. 透過周轉率、法人買超與均線位置尋找短線人氣股。

這是一張「下週哪個族群可能接棒」的盤面地圖，不是完整的公司研究。

## 二、最重要的投資框架：影片其實在做事件、動能、基本面三層分工

```text
事件催化劑：法說、財報、預算、處置出關、漲價函
→ 資金動能：成交量、周轉率、法人買超、突破均線
→ 基本面驗證：營收、EPS、毛利率、訂單與下半年展望
```

這個框架合理，但影片在多數段落只完成前兩層，第三層通常只點到為止。因此若要拿來操作，必須再補：

- 事件會影響多少營收與獲利。
- 利多是否已提前反映。
- 事件失效時的賣出條件。
- 短線持有週期是否與公司基本面驗證時間相符。

## 三、NVIDIA：影片把財報定位成「錦上添花」，這個判斷合理

影片提到NVIDIA將於8月26日公布FY2027第二季財報，官方投資人關係頁面確認該日期與時間。[2]

影片的重點不是猜EPS，而是觀察：

- AI需求是否仍然強。
- NVIDIA能否繼續創高。
- 5,000億美元AI融資敘事是否得到財報支持。
- 財報好是否已反映在股價。

這比單純預測「財報會不會超預期」好。因為AI龍頭目前需要的不是單次好數字，而是：

```text
營收成長
＋毛利率
＋下一季指引
＋客戶資本支出
＋AI基礎設施融資能否轉成實際訂單
```

影片把NVIDIA視為整個AI族群的情緒指標，短線合理；但不能因NVIDIA股價強弱，直接判定所有台股AI供應鏈基本面同步改變。

## 四、記憶體：影片的主軸大致正確，但「中國記憶體是鬼故事」不能當成固定結論

影片提到Apple測試中國記憶體、以及美國商務部長Lutnick反對美國企業採購中國記憶體。公開報導顯示，Apple確實被報導正在測試CXMT記憶體，並評估在中國市場產品使用；但Apple沒有公開確認已完成供應商認證或已下單。[5]

因此這個事件的正確判讀是：

```text
Apple尋找中國記憶體替代料
→ 市場擔心中國供應增加、壓低記憶體價格
→ 美國政策與供應鏈安全形成限制
→ 短期實際供應增加仍不確定
```

對南亞科、華邦電、旺宏等台廠的影響，不能只看「Apple有沒有測試」，要看：

1. CXMT實際可供產能。
2. 是否通過完整認證。
3. 是否只限中國市場。
4. 美國是否改變出口與採購限制。
5. DRAM供給增加的速度是否低於AI伺服器需求增加速度。

影片稱這個利空可能是「鬼故事」，短線上有道理，但不能因此忽略中國記憶體長期擴產的供給風險。

### 南亞科是影片中最值得留下的觀察對象

影片提到南亞科創高後翻黑，並認為趨勢沒有立即破壞。公開資料顯示，南亞科2026年7月營收438.68億元，年增719.61%，前7月累計年增660.87%，且公司說明新舊合約交替後新合約自7月生效。[3]

這支持「基本面仍強」的判斷，但不代表股價不會修正。記憶體股要分兩層看：

- **基本面：** 報價、合約、出貨、毛利率、產能利用率。
- **交易面：** 股價是否提前反映兩年以上獲利、法人是否轉賣、長黑是否跌破趨勢線。

影片提供的操作邏輯「不要因單日翻黑就立刻殺出，但要設明確均線和動能條件」，比較適合短線波段，不適合沒有風控的長抱。

## 五、南亞CCL漲價：影片抓到事件，但市場最容易把20%誤當成公司正式指引

影片提到市場流傳南亞自9月1日起將CCL及基材全面調漲20%。南亞回應確實有因應原料成本上漲而與客戶協商調價，但流出的文件不是公司正式對外漲價通知，也不是所有產品與客戶一次性全面調漲20%。[3]

因此要拆成三個層次：

- **已確認：** 南亞今年多次調整電子材料產品價格。
- **已確認：** 玻纖布與銅箔供應緊張，成本壓力存在。[3]
- **未確認：** 全產品、全客戶、一次性平均調漲20%。

這對1303南亞的投資含義不是「20%漲價直接乘營收」，而是要看：

```text
價格調升幅度
− 銅箔、玻纖布、樹脂成本增幅
= 實際毛利率改善幅度
```

而且南亞獲利還受到南亞科等轉投資影響，不能把整家公司直接當純CCL股。

## 六、無人機：634億元預算是真的，但不是當季營收

立法院於2026年8月14日通過合計634億元的無人載具相關預算，包括經濟部六年442億元產業發展計畫，以及各部會192億元採購預算。[4]

影片把它視為漢翔、雷虎、亞航、晟田等軍工股的短線催化劑，方向合理。但必須避免三個跳躍：

```text
預算通過
≠ 訂單已分配
≠ 公司已認列營收
```

後續要追：

1. 採購標案何時公告。
2. 規格與得標廠商。
3. 國產化比例。
4. 交貨期與驗收方式。
5. 毛利率是否高於原有航太代工業務。
6. 美國關稅與在地生產要求是否侵蝕出口利潤。

所以無人機目前是政策催化的事件交易，除非看到標案、訂單和認列時程，否則不能直接當成長期成長股。

## 七、晶技3042：影片數字大致正確，且是本片較有基本面內容的個股

晶技上半年營收70.38億元，年增7.75%，稅後純益10.05億元，EPS 2.96元，這些數字有公開報導支持。[6]

影片把法說會重點放在：

- AI高速傳輸石英元件。
- 車用產品。
- 下半年展望。
- 是否突破季線壓力。

這個觀察方向合理。晶技的研究不能只看「石英元件會漲」，而要看：

```text
AI營收占比
→ 156MHz到312MHz產品升級
→ ASP與毛利率
→ 新設備投產
→ 2027年AI產品占比是否提高
```

若AI產品占比提高但毛利率沒有改善，代表公司可能只是放量而非產品升級成功。

## 八、周轉率：影片解釋正確，但它是人氣指標，不是價值指標

周轉率可以看出：

- 股票當天交易是否熱絡。
- 籌碼是否快速換手。
- 題材是否吸引資金。
- 股價上漲是否有足夠流動性支撐。

但周轉率高可能代表兩種完全相反的狀況：

```text
多方接力，人氣增加
或
高檔派發，籌碼互砍
```

所以周轉率一定要和以下指標一起看：

- 股價位置。
- 收盤強弱。
- 成交量是否爆量滯漲。
- 法人買賣超。
- 融資與當沖比例。
- 隔日是否有延續性。

影片說「題材股需要有人交易」是對的，但「有人交易」不等於「值得持有」。

## 九、我對影片的總評

### 合理的地方

1. 把財報、法說、處置出關和政策消息放進同一週的催化劑地圖。
2. 不把單日翻黑直接解讀成記憶體多頭結束。
3. 知道無人機預算是中期訂單催化，不是當日營收。
4. 能區分自己的操作流派與別人的交易風格。
5. 對周轉率的解釋適合新手理解。

### 需要打折的地方

1. 影片大量依賴技術線型和短線價位，不能取代基本面研究。
2. 「法人狂掃」不等於法人看好未來獲利，可能只是指數、ETF或事件性調倉。
3. 20%漲價函並非南亞全面正式指引。[3]
4. 634億元預算不等於軍工股立即得到等額訂單。[4]
5. 中國記憶體短期利空可能被政策壓制，但長期供給增加仍是風險。[5]
6. 處置出關後若成交量暴增，可能是解鎖流動性，也可能是高檔換手，必須看出關後三日價格與成交量。[7]

## 十、對製作人的可操作結論

這支影片可以當作「本週事件雷達」，不能當作買進清單。

### 優先追蹤

- **記憶體：** 南亞科、華邦電、旺宏，重點看報價、合約和趨勢線，不追單日創高。
- **CCL與玻纖布：** 南亞、富喬，重點看實際調價、成本轉嫁和毛利率，不把20%傳聞當指引。
- **石英元件：** 晶技、希華，重點看AI營收占比、法說展望、漲價後毛利率。
- **無人機：** 漢翔、雷虎、亞航，重點看標案與訂單，不只看634億元題材。
- **處置出關股：** 出關後先看三日成交量、收盤位置和法人籌碼，不因恢復正常交易就追價。

### 最重要的交易原則

```text
事件提供方向
技術面決定進場與退場
基本面決定能不能持有
估值決定部位大小
```

影片最值得留下的一句話不是某一檔會漲，而是：

> **不要把別人的交易流派當成自己的答案。先確認自己的持有週期、可承受回撤與退出條件。**
