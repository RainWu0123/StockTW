# 創意（3443）：台積電生態系的 ASIC 白手套

**報告日期**: 2026-08-22
**信心等級**: **高**
**策略類型**: 核心成長股（2027 EPS 年增近一倍的重估故事）

> **一句話結論：Q2 營收年增 128%、EPS 11.61 元超預期，證實取得北美 CSP 大客戶下一代案子；法人估 2027 CPU 出貨上看 200 萬顆＋二代 CPU Q4 tape-out，歐系外資估 2026-2028 EPS 52.96/104.14/155.25——兩年三倍的獲利曲線。目標價 6,500 元對當時股價有 88% 空間。我採用 Base 目標價 6,500 元，BUY／分批——它是台積電 AI ASIC 大爆發最直接的設計服務槓桿。**

## 商業模式：「由下往上」的差異化

| 要素 | 內容 |
|---|---|
| 定位 | 不與博通正面競爭；從先進封裝＋後段實作切入，向上延伸到 Physical Implementation |
| 核心優勢 | 與台積電合作的先進封裝能力「比大型 Design House 還強」 |
| 客戶結構 | 雲端占營收 79%；北美 CSP CPU 專案已跑近兩年、下一案已到手 |
| Turnkey | TK1/TK2/TK3 分層收費；TK3 毛利率低但擴大規模 |
| CPO | 已有新創客戶＋大型客戶接洽中 |

## 主題與近期催化劑

**主題**：CSP 自研 CPU/ASIC 放量／CoWoS 產能紅利／CPO IP

**近期催化劑**：
- 北美 CSP 二代 CPU Q4 tape-out，單價高於一代；法人估一代 200 萬顆＋二代 50 萬顆貢獻營收 25 億美元+
- CPU:CSP ASIC 配比從 1:4 升至 1:2 → 2027 CPU 至少 200 萬顆
- 圖靈中心全面運作（3 奈米/2 奈米/高階封裝）
- 為客戶備料 CoWoS 產能與 HBM4——下一代 ASIC 的入場券
- 台積電明年產能配置 1~2 個月內明朗
