# 精確（3162）：Cooler Master Vendor Code 是入場券，獲利仍在門外

> 一句話結論：精確的新能源車本業把營收推到新高，液冷子公司也取得 Cooler Master Vendor Code；但 2026H1 EPS 只有約 0.05 元，液冷營收仍約 4% 至 5%。這是「營收成長已確認、液冷資格已確認、獲利轉化尚未確認」的高波動轉機股，維持 WATCH，不把供應商代碼當成大單。

## 本業是新能源車金屬件，AI 液冷才是估值選擇權

精確原本靠鋁合金壓鑄、精密加工與新能源車電池盒賺錢。2026 年營收成長主要仍由中國新能源車客戶、華為相關車款、塞爾維亞廠與自動化設備帶動，而不是 AI 液冷。

液冷業務由精確持股 55% 的浙江精諾智流承接，產品涵蓋：

- 不鏽鋼分歧管（Manifold）
- 水冷板（Cold Plate）
- 冷卻液分配裝置（CDU）
- 電池備援模組（BBU）
- 浸沒式液冷櫃（TANK）

價值分配上，精確提供精密金屬加工、量產與組裝能力；液冷合作夥伴提供系統設計與客戶認證。若只供應 Manifold，收入密度與毛利天花板低於 CDU／完整系統；因此「有液冷營收」和「液冷能顯著改善 EPS」是兩個不同命題。

## Vendor Code 證明資格，不證明訂單

2026-08-24 至 25 日，公司確認取得 Cooler Master（訊凱國際）Vendor Code，正式成為合格供應商。這代表技術、品質與供應體系跨過門檻，但尚未揭露：

- 正式訂單金額。
- 最低採購量與合約期限。
- 量產產品是 Manifold、Cold Plate 還是 CDU。
- 單位毛利率與精確可認列的持股後收益。

目前 Manifold 出貨量體最大，已有台系散熱客戶；浸沒式液冷櫃小量供貨台系 ODM；Cold Plate 已具量產能力但仍送樣；CDU、BBU 仍在驗證。液冷散熱營收約占 4% 至 5%，仍屬低個位數。

### Driver Chain

Cooler Master Vendor Code
→ 取得報價與量產資格，但仍需專案訂單
→ Manifold／Cold Plate／CDU 由送樣轉量產，提前 3 至 6 個月備料
→ 液冷占比由 4% 至 5% 升至 10% 以上，產品組合改善
→ 毛利率與營業利益率回升，H1 的低 EPS 才可能改善
→ 市場才有理由由車用零件估值轉向 AI 散熱估值。

目前證據只走到「資格＋部分小量出貨」，尚未走到大規模收入與獲利。

## 營收創高是真的，但獲利幾乎沒有跟上

| 指標 | 數值 | 判讀 |
|---|---:|---|
| 2026Q2 營收 | 23.87 億元，季增 22%、年增 31.9% | 規模創高 |
| 2026Q2 稅後淨利 | 約 435 萬元 | 獲利率極薄 |
| 2026Q2 EPS | 約 0.03 元 | 營收尚未轉成每股盈餘 |
| 2026H1 EPS | 約 0.05 元 | 低於題材股估值所隱含的成長 |
| 2026年7月營收 | 10.76 億元，月增 19.88%、年增 77.54% | 單月首破 10 億、創高 |
| 前7月營收 | 54.07 億元，年增 24.6% | 本業需求強 |
| 液冷營收占比 | 約 4% 至 5% | 尚未成為主體 |

Q2 營收創高但 EPS 只有約 0.03 元，原因包括鋁價與原料成本、車用本業毛利偏低、新事業費用及液冷占比仍小。這是最重要的反證：題材已有，單位經濟尚未證明。

## 和成熟散熱廠的差距不在產品名稱，而在量產與客戶黏著

精確可以列出與奇鋐、雙鴻、Cooler Master 相似的液冷產品名稱，但商業位置不同：

- 成熟散熱廠掌握模組設計、系統整合、長期客戶共同開發與大規模量產。
- 精確目前優勢是金屬加工、壓鑄、全球車用製造據點與成本控制。
- 弱點是 AI 客戶關係、液冷系統驗證歷史、訂單能見度與非中國產能仍在建立。

取得 Vendor Code 後，真正要追的是重複訂單、良率、交付與售後，不是再增加一個「打入供應鏈」標題。

## 市場已先定價液冷轉機，暫時沒有可靠目標價錨

2026-08-26 盤中曾漲停至 73.3 元。以 H1 EPS 約 0.05 元或近四季 EPS 約 1 元上下衡量，傳統 PE 會嚴重失真；市場定價的是 2027 液冷占比大幅提升，而不是目前獲利。

在缺少液冷訂單、毛利與量產數據前，不硬給單一目標價：

- **Bear：**Vendor Code 未轉成量產，液冷占比停在 5% 以下，車用本業毛利受鋁價壓縮，股價回歸車用零件估值。
- **Base：**Manifold 穩定出貨，Cold Plate 小量量產，液冷占比約 8% 至 10%，但 CDU 尚未放量。
- **Bull：**Cooler Master 與其他 3 至 4 家客戶轉成重複訂單，CDU／Cold Plate 量產，2027 液冷占比達 20% 以上且整體毛利率明顯改善。

## 風險與否決條件

1. 取得 Vendor Code 後兩季仍沒有可量化訂單或液冷占比提升。
2. 連續兩季營收成長但營益率低於 2%，代表規模沒有帶來獲利。
3. Cold Plate、CDU 或 BBU 驗證延後，業務長期停在低價值 Manifold。
4. 中國液冷子公司只貢獻營收，少數股權、費用與資本支出稀釋母公司 EPS。
5. 7,000 萬股私募若執行，造成顯著股權稀釋。
6. 非中國量產據點沒有按客戶要求建立，無法進入北美供應鏈。

## 研究判斷

- 類型：新能源車本業＋AI 液冷高波動轉機。
- 成熟度：60。營收與供應商資格已確認，液冷訂單、毛利、現金流與 ROIC 尚缺。
- 判斷：**WATCH，不追認證漲停。** 下一個升級點不是新聞，而是液冷占比突破 10%、營益率改善，以及 Cooler Master 訂單金額出現。
