# 雙鴻（3324）：重返 Rubin 供應鏈的液冷純度股

**報告日期**: 2026-08-22
**信心等級**: **高**
**策略類型**: 長期成長股（液冷滲透率最大受惠者之一）

> **一句話結論：Q2 營收逆淡季創高（年增 64%）、7 月營收年增 117% 單月新高、下半年液冷占營收將達 70%——雙鴻是台系散熱廠中「液冷純度」提升最快的公司。外資目標價 1,280~1,640 元分歧來自消費性拖累與分歧管競爭。我取 Base 目標價 1,400 元（2026 EPS 約 51 元 × 27 倍），BUY／分批——液冷產業趨勢明確，雙鴻的供應內容正在變寬。**

## 商業模式：從水冷板到一條龍液冷方案

| 產品 | 狀態 | 意義 |
|---|---|---|
| GPU 水冷板＋Manifold | GB300 加單；美超微主要供應商 | 基本盤放量 |
| CDU | 台灣生產、保留擴產空間 | 一條龍拼圖 |
| QD 快接頭 | 自製比 5%→30%（GB300 切入後） | 主導設計，單機櫃價值提升 |
| DIMM Cold Plate | 已完成驗證、與 DRAM 原廠共同推進 | 單價與毛利優於傳統冷板 |
| 光通訊模組液冷 | 推進中 | 新應用 |
| CPU 液冷＋ASIC 專案 | Q4 放量接力 | 成長第二波 |

關鍵里程碑：**部分產品已重回 NVIDIA Vera Rubin 合格供應商名單**——這是雙鴻從「被踢出」到「重返」的地位修復。

## 主題與近期催化劑

**主題**：液冷滲透率起飛／Rubin 重返／QD 自製化

**近期催化劑**：
- 全年營收年增 60~70% 目標不變；全年 EPS 法人估約 51 元（年增 81%）
- 下半年液冷單月營收占比達 70%；明年水冷比重上看 95%
- xAI 大幅上修下半年 GB300 訂單 → 美超微/緯創受惠 → 雙鴻跟著受惠
- Q3 訂單遞延回補＋GB300 追單；Q4 CPU 液冷＋DIMM 冷板＋ASIC 專案三箭
- 產能：台灣/中國/泰國布局完整
