# 南亞科（2408）：DRAM價格創造近80%毛利率，最大風險是把高峰當常態

> **結論：以2026年8月20日收盤517元為基準，我把南亞科12個月目標價由初版600元下修至380元，合理區間350～420元，判斷REDUCE／不追價。正式核閱財報顯示私募後股數增加約10.2%，而517元已接近需要未來12月EPS 65～75元與長時間高毛利的Bull情境。**[22][23][18]


## 主題與近期催化劑

**主題**：DRAM超級週期/標準DRAM

**近期催化劑**：
- 大摩維持南亞科目標價580元、DDR4 Q3漲50%直接受惠
- 7月營收438.68億元年增逾倍、新合約價生效
- 5A新廠3,500億投資啟動（2028供需恢復平衡的遠期風險）

## 先糾正定位：南亞科不是HBM3E／HBM4核心供應商

南亞科主力仍為DDR5、LPDDR5／5X、DDR4、LPDDR4／4X、DDR3等DRAM。公司已增加AI基礎設施與伺服器產品，H1相關營收占比超過20%，並發展客製化AI、WoW與先進封裝合作，但目前不能把它直接等同SK hynix、Micron、Samsung的HBM供應商。[6]

正確投資論點是：全球三大廠把先進產能與資本支出優先投向HBM、server DRAM與高階產品，排擠傳統DRAM供給，南亞科因此享受DDR4／LPDDR／DDR5價格與產品組合紅利。

## Q2財報：出貨沒增加，價格就把獲利推到歷史極端

| 項目 | 2026Q2 | QoQ |
|---|---:|---:|
| 營收 | 825.49億元 | +68.2% |
| ASP | 季增逾60% | 主要成長來源 |
| 位元出貨 | 約持平 | 無量增 |
| 毛利率 | 79.5% | +11.6個百分點 |
| 營益率 | 73.7% | +12.4個百分點 |
| 稅後淨利 | 501.92億元 | +92.6% |
| EPS | 14.66元 | Q1為8.41元 |

H1 EPS 23.38元、每股淨值93.49元。[6]

這張財報的Driver Chain非常乾淨：

```text
HBM與server DRAM排擠供給
→ 傳統DRAM供不應求
→ 南亞科Q2 ASP季增逾60%
→ 位元出貨持平但毛利率升至79.5%
→ EPS跳升至14.66元
```

所以後續最重要的不是單月營收創高，而是ASP增幅是否由+60%降到+20%、持平，最後轉跌。

## 同業財報確認超級週期，但也顯示獲利率已在高峰區

Micron FQ3 DRAM ASP季增約60%、NAND ASP約85%，毛利率約85%；SK hynix Q2營益率76%；Samsung Memory也創營收與營業利益新高，並預期H2 server DRAM、eSSD與HBM持續供不應求。[14][15][16]

這支持南亞科Q3價格仍強。但當全球原廠毛利率都在70%～80%以上，市場已經知道供應短缺，任何「漲幅低於預期」都可能被當成週期見頂。

## LTA提高能見度，不等於鎖定毛利率

公司正與客戶把單季合約拉長為年度甚至多年LTA；市場報導稱LTA覆蓋可能接近一半產能，且AI相關占比將提高。[9]

但公開資訊未完整揭露：

- 固定價與浮動價比例。
- Take-or-pay條款。
- 客戶取消或重談條件。
- 每年價格重設方式。

LTA可以保出貨，不一定保79.5%毛利率。若合約跟隨市場價格調整，DRAM轉跌時EPS仍會下降。

## 5A新廠是長期升級，也是3466億元資本豪賭

董事會把2026資本支出上限由520億提高至697億元；2026～2029年5A新廠第一階段資本支出上限3,466億元，目標月產能35,900片，最終規畫45,000片，導入1B／1C／1D／1E與EUV。2027下半年投片，2028月產30,000片，2029提高至35,900片。[7]

正面：

- 補上先進製程與成本競爭力。
- 提高DDR5、LPDDR5與客製化AI產品能力。
- 產能開出時間晚，短期不會立刻破壞供需。

風險：

- 大額設備預付款、折舊與EUV學習曲線。
- 2028～2029若產業供給同步開出，可能踩到週期下行。
- 新廠還沒營收前，現金流與ROIC先承壓。

公司法說揭露全產能投資估計約4,800億元；董事會後續核准的3,466億元是5A新廠階段性資本支出上限，兩者口徑不能混為同一個總額。[7][23]

## 現金、私募與稀釋

Q2核閱財報顯示，6月底現金及約當現金2,176.03億元，扣除公司債與長期借款後淨金融現金約1,992億元；H1營業現金流874.08億元，簡化自由現金流約805.52億元。南亞科的資產負債表不是問題，問題是新股與高峰估值。[22]

公司私募增發約3.516億股、約稀釋10.2%，由Kioxia、SanDisk、Solidigm等策略投資人參與；H1基本EPS 23.38元，稀釋EPS22.48元。初版估值未完整納入此分母變化，必須修正。[22]

## 法人報告

- FactSet 14位分析師：2026 EPS中位數57.72元、2027中位數82.64元，目標價548元；2027 EPS區間46.22～93.08元。[8]
- 未揭露法人：2026 EPS 75.1元、目標價720元，假設Q3 ASP再漲50%。
- 另一份未揭露法人：2027 EPS 140.92元、目標價1,000元，重押LTA、AI占比與產品升級。[9]
- 早期報告目標545～650元，多採2026 EPS約54元×10倍，或2027 EPS約92元×7倍。

1000元情境不是不可能，但需要2027 EPS約125～141元且市場仍願意給7～8倍PE；這遠高於FactSet共識。

## 自建估值

| 情境 | 2027正常化EPS | PE | 目標價 |
|---|---:|---:|---:|
| 空頭 | 25.4元 | 約10倍 | 250元 |
| **基準** | **48.7元** | **約8倍** | **380元** |
| 多頭 | 78.4元 | 約7倍 | 545元 |

基準情境假設未來12月營收4,200億元、淨利率40%，採私募後股數計算EPS約48.7元；P/E價值約390元，前瞻BVPS 125元×3倍約375元，交叉取380元。FactSet 82.64元與樂觀法人140.92元均高於官方財報稀釋後的保守邊界，前者可能未完整反映最新私募與週期回落。

P/B交叉檢查：517元約為Q2每股淨值93.53元的5.5倍，已經隱含高ROE延續；即使Bull目標545元，上行也只有約5%。

## 操作與否決條件

- 350～400元：才進入基準合理區。
- 300～350元：若ASP與同業指引未轉弱，可觀察分批。
- 500～545元：接近Bull上限，持有者應設停利條件。
- 545元以上：不靠更高ASP與EPS上修就沒有安全邊際。

否決條件：DRAM ASP季增跌破10%後轉負、位元出貨下降、高階產品占比停滯、LTA被重談、5A CapEx再大幅上修、Micron／SK hynix／Samsung同時轉向擴產或下修價格展望。
