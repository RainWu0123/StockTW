# 金像電（2368）：AI 伺服器與 ASIC PCB 需求強，但價格轉嫁、HDI 良率與新廠折舊決定獲利品質

> **一句話結論：**金像電 2026Q2 營收242.79億元、年增75.3%，毛利率34.65%、EPS約9.27元；H1 EPS16.14元。AI伺服器、高階交換器與ASIC客戶拉貨強，7月營收突破百億元，但CCL成本轉嫁有時差，泰國與新產能增加折舊，HDI良率仍需驗證。我給Base 1,600元，1,800元留給毛利率回升至37%以上的Bull。

## 商業模式與護城河

金像電製造高層數伺服器 PCB、高速交換器板、ASIC主板與 HDI。AI伺服器需要更多層數、更低損耗、更厚銅與更高可靠度，產品價值由板層、材料、良率與客戶認證共同決定。護城河是高階板設計與量產、ASIC客戶共同開發、HDI製程與大規模產能；限制是材料成本、客戶集中、良率和新廠爬坡。

## 財務與產能

- Q2 營收242.79億元，季增約25.7%、年增75.3%；毛利率34.65%；營益率約26.4%；EPS約9.27元。
- H1 營收435.92億元，年增約70%；H1 EPS16.14元。
- 7月營收100.15億元，年增77.4%；單月創高支持需求強，但不代表價格與毛利同步改善。
- Q2毛利受 CCL 漲價與轉嫁時差、新廠折舊、網通產品較弱影響；泰國廠轉盈是正面，但後續仍看稼動率。
- HDI與新ASIC平台是成長選項，外部機構對良率與新案時程的推估不是公司承諾。

**Driver Chain：**AI／ASIC與高速交換器升級 → 高層數、HDI與低損耗 PCB 需求增加 → 金像電以認證與產能承接 → ASP與產品組合改善 → 毛利率與現金流提升。失效點是 CCL 漲價無法轉嫁、HDI良率不穩、客戶轉單或新廠折舊超前。
