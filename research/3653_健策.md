# 健策（3653）：AI 散熱規格升級已反映在獲利，下一個驗證是新品 ASP、良率與現金流

> **一句話結論：**健策 2026Q2 營收 72.75 億元、年增 40.4%，毛利率 46.81%、EPS 15.80 元，均熱片高階產品放量已經轉化為實際獲利。但市場目前同時交易 Rubin、Rubin Ultra、CPU Socket 與 ASIC 四個成長選項，其中部分時程與 ASP 仍是法人推估，不是公司保證。我給 Base 目標價 6,100 元，偏多但不追高，估值必須建立在新品量產與高毛利率可持續，而不是單季 EPS 外推。

## 商業模式與護城河

健策提供精密沖壓、金屬機構件、均熱片、GPU／CPU 蓋板、Stiffener、Socket 與車用散熱模組。AI 伺服器中，晶片功耗提升會推高晶片級散熱的接觸面、材料、平整度、真空腔體與製程良率要求，產品不是一般金屬加工件，而是影響晶片可靠度與系統效能的關鍵零組件。

護城河來自三層：第一，精密加工、薄型結構、材料與散熱性能整合；第二，通過 GPU／CPU 平台認證後，客戶更換供應商會牽涉重新驗證與量產風險；第三，能從均熱片延伸到一體式蓋板、可拆式蓋板、Stiffener 與 CPU Socket，吃到單機價值提升。限制則是客戶集中、平台世代轉換快、產品良率與價格需要持續維持。

## 營收、訂單、產能與能見度

- 2026Q2 營收 72.75 億元，季增 37.12%、年增 40.40%；毛利率 46.81%，營業利益率 37.79%；稅後淨利 23.18 億元，EPS 15.80 元。
- 2026H1 營收 125.80 億元，年增 26.64%；毛利率 44.69%；稅後淨利 37.17 億元，EPS 25.33 元。
- Q2 散熱片約占營收 75.1%，年增約 40.1%；導線架約 8.6%，電子零組件約 5.8%。產品組合顯示散熱已是主引擎，不再只是選配題材。
- B300 平台持續放量，Rubin 相關均熱片開始貢獻；下半年能否再創高，要看平台出貨、產品組合與客戶拉貨，而非只看 NVIDIA 發表時程。
- CPU Socket 已取得美系 CPU 大廠認證，市場資料指向最快 2026Q4 出貨；正式貢獻規模與毛利率尚未公開，列為待驗證新引擎。
- 大園新廠已投入營運，並持續擴充均熱片、連接器扣件與車用水冷散熱模組產能；擴產能否同步帶來現金流與合理稼動率，需觀察存貨、應收帳款與營業現金流。
- 可拆式蓋板 ASP 超過 200 美元、Rubin Ultra 2027Q2 出貨、單價較現行平台翻倍，均屬外部法人／市場估算，不能當作已確認訂單。

**Driver Chain：**GPU／ASIC 功耗上升 → 均熱片、蓋板與 Stiffener 規格升級 → 客戶認證與高階產品放量 → 單機價值與產品毛利提升 → 健策營收、毛利與 EPS 成長。失效點是新平台延遲、良率不達標、ASP 被客戶壓低、客戶自製或供應商分散，以及擴產造成折舊與營運資金壓力。

## 同業比較

| 公司 | 主要位置 | AI散熱／機構能力 | 相對優勢與限制 |
|---|---|---|---|
| 健策 | 晶片級均熱片、蓋板、Socket | GPU、CPU、ASIC平台 | 高毛利與認證壁壘強，但估值與客戶集中風險高 |
| 奇鋐 | 散熱模組、熱管、機櫃液冷 | GPU伺服器與液冷系統 | 系統散熱規模大，產品組合不同 |
| 雙鴻 | 熱管、均熱片、液冷 | GPU、伺服器散熱 | 直接散熱同業，客戶與平台組合不同 |
| 台達電 | 電源、風扇、液冷與系統整合 | 資料中心基礎設施 | 規模與系統能力強，並非單一晶片散熱純標的 |

健策不能只拿同業營收增速比較，核心是散熱片占比、單位產品價值、毛利率、良率、客戶認證與現金轉換。若高毛利新產品比重上升但應收帳款與存貨同步失控，獲利品質會打折。

## 估值：高品質成長也需要安全邊際

| 情境 | 核心假設 | 2027 EPS | PE | 目標價 |
|---|---|---:|---:|---:|
| Bear | Rubin／CPU Socket 延遲，ASP與良率低於預期 | 105 | 35x | 3,675 |
| **Base** | B300與Rubin續放量，CPU Socket逐步貢獻，毛利率約 47%～49% | **135** | **45x** | **6,075，取 6,100** |
| Bull | 高階蓋板與ASIC全面放量，毛利率站上 50% | 175 | 50x | 8,750 |

外資曾給 6,100～6,770 元目標價，部分模型採 2027～2028 年 EPS 137～206 元，並假設毛利率持續升至 50% 以上。這些是 sell-side 情境。我的 Base 將 2027 EPS 設為 135 元，並把 6,770 元以上視為需要新品 ASP、出貨與毛利率同時超預期的 Bull 區間。

## 籌碼、催化劑與否決條件

健策是高預期、高股價波動標的，法人常以平台世代與單機價值提前估值。短期催化劑是 Q3 出貨與 Q4 CPU Socket，真正重估則需要新品量產後的連續財報。限制型股票費用也會使 EPS 與本業獲利分離，需看營業利益而非只看每股盈餘。

**上修條件：**

1. Q3 營收與毛利率同步成長，且增長來自實際高階產品放量。
2. 可拆式蓋板 ASP、良率與量產客戶獲得正式財報或法說佐證。
3. CPU Socket 於 2026Q4 如期出貨，並公布可觀察的營收貢獻。
4. 毛利率維持 47% 以上，營業現金流跟上淨利成長。

**賣出／否決條件：**

1. 新平台延遲超過兩季，或 CPU Socket 認證後未轉量產。
2. 毛利率連兩季跌破 43%，且無法由產品組合或一次性費用解釋。
3. 存貨與應收帳款增速持續高於營收，營業現金流轉負並惡化。
4. 高階均熱片或蓋板 ASP 明顯低於法人模型，代表議價權被高估。
5. 客戶分散供應、改用替代設計，導致健策單一平台份額下降。
