# 力旺（3529）：先進製程與 Security IP 推升權利金，但高估值要求量產轉換率持續兑现

> **一句話結論：**力旺 2026Q2營收10.97億元、營益率60.7%、EPS7.77元；H1營收21.91億元、EPS15.75元。3～7奈米開案55案、PUF Security IP快速成長、3奈米產品已進入量產，先進製程授權收入占比超過50%。但授權金、權利金、Tape-out與最終晶圓出貨之間存在時間差，我給Base 3,330元，不用最高倍數直接外推。

## 商業模式與護城河

力旺以一次性授權金與量產後權利金為核心，提供NeoFuse、NeoBit、MTP、PUF、OTP與Security Subsystem。護城河是IP驗證、晶圓廠平台相容、客戶導入週期與高切換成本；IP不需自建晶圓產能，因此邊際毛利高，但收入取決於客戶晶片是否成功量產。

## 財務與量產轉換

- Q2營收10.97億元，季增0.3%、年增17.1%；營益率60.7%；淨利5.8億元；EPS7.77元。
- H1營收21.91億元，年增18.5%；營益率60.6%；淨利11.76億元，年增36.5%；EPS15.75元。
- 3～7奈米開案累積55案；先進製程專案占授權收入超過50%，單案授權價格可達平均數倍。
- PUF Security IP H1占營收約11.6%，授權與權利金高速成長；已延伸至AI CPU、BMC、SSD、CXL、FPGA與光通訊。
- Q2完成156個產品Tape-out，代表未來權利金管線，不等於已認列收入；3奈米產品已有數百片晶圓出貨，明年貢獻仍需看放量。
- 總經理退休後的管理層交接是短期執行風險，不影響既有IP但可能影響客戶溝通與市場估值。

**Driver Chain：**製程微縮與AI晶片複雜度上升 → OTP／PUF／Security Subsystem需求增加 → 客戶授權與Tape-out → 晶圓量產 → 權利金放大。失效點是客戶專案延遲、晶圓廠稼動率下降、IP被替代或授權案無法轉量產。
