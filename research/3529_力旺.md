## 商業模式：先收授權金，再終身抽權利金

力旺是台灣最純粹的 IP 公司：客戶先付授權金（NRE），量產後每片晶圓抽權利金。這個模式的財務特徵：

| 指標 | 數值 | 意義 |
|---|---:|---|
| 營益率 | 60.7% | IP 沒有製造成本，邊際獲利極高 |
| 權利金占營收 | 65% | 高度重複性收入 |
| Q2 Tape-out | 156 個產品 | 未來權利金的存糧 |

產品結構（Q1 法說資料）：NeoFuse 59.8%、NeoBit 20%、PUF Security IP 12.2%、MTP 8%。

### Q2 權利金下滑的真相

Q2 權利金較 Q1 下滑，公司解釋：權利金認列反映**前一季**晶圓代工出貨，Q1 產能利用率低檔＋客戶季節性庫存調整。Q2 起產能利用率已改善＋晶圓價格調升——權利金跟著晶圓出貨量與單價連動，**代工漲價對力旺是純利多**（費率按晶圓價值抽成）。

### PUF 是第二成長曲線

H1 PUF Security IP 占營收 11.6%，授權金年增 264.6%、權利金年增逾 13 倍。AI 伺服器走向 Chiplet/CXL 架構後，需要硬體信任根的晶片數量從「少數幾顆」變成「每一顆」——這是安全 IP 的市場規模重定義。力旺正從賣單一 IP 轉向賣 Security Subsystem，單顆晶片的 IP 價值持續提升。
